# Personal-Journal-Program

This is a simple Python program that allows users to create and save personal journal entries. It uses a text file called 'journal.txt' to store entries so previous entries are not deleted. The program also includes a menu to add entries, read saved entries, or exit. It uses try and except to handle file errors and a global counter to keep track of entries saved during each run.

## Features
- Add journal entries.
- Save entries to a text file.
- Read previously saved entries.
- Count entries saved during the current run.
- Handle file errors using try and except.

## How to Run
1. Open the Python file.
2. Run the program.
3. Choose an option from the menu.
4. Add or read journal entries.
